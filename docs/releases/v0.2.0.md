# AI Skill Shield v0.2.0

Released August 2, 2026.

AI Skill Shield v0.2.0 turns the original skill validator into a practical pre-install review workflow for AI agent skills and their repositories.

## Try it

Use the hosted scanner at [ai-skill-shield.suppeng.com](https://ai-skill-shield.suppeng.com/). Standard static scans require no installation, account, or API key.

Paste a GitHub or `skills.sh` URL, upload skill files, or paste a `SKILL.md`. AI Skill Shield returns an install verdict, risky-line evidence, repository trust signals, and exportable findings.

## Highlights

- Audits repository install surfaces before trust: lifecycle scripts, custom registries, workflows, submodules, and dangerous commands.
- Finds and validates every `SKILL.md` in multi-skill repositories, then produces a combined repository verdict.
- Handles larger repositories with prioritized security-file selection, batched downloads, and retry support.
- Shows `Safe to Review`, `Needs Manual Review`, or `Do Not Install` with the evidence behind the decision.
- Adds repository metadata, install-surface maps, dangerous file and line references, approval actions, public trust pages, and badge endpoints.
- Exports JSON, HTML, print-friendly HTML, and SARIF reports.
- Supports optional AI review through OpenAI, Anthropic, OpenCode Go, and OpenCode Zen when self-hosted.

## CLI asset

This release includes `skillshield-cli-0.2.0.tgz` for compact local scans:

```bash
npm install --global https://github.com/adnan-iz/ai-skill-shield/releases/download/v0.2.0/skillshield-cli-0.2.0.tgz
skillshield scan ./path/to/skill
```

SHA-256: `1e0f51f4a1bcddd75fd5eac8248fc79e3d5f7bc7e033b7f655a18a07add108b7`

The CLI uses a smaller local rule set. Use the hosted scanner for complete GitHub repository auditing and the full 11-axis report.

## Upgrade notes

The default branch is now `master`; the old `v2.00-dev` branch was removed. Existing clones can move to the new branch with:

```bash
git fetch origin
git switch master
git pull --ff-only
npm ci
```

There are no application data migrations required for this release.

## Security and reliability

- Updated Next.js to 16.2.12 and pinned Sharp to a patched release.
- Fixed large-repository imports, multi-skill discovery, GitHub path resolution, verdict thresholds, report recovery, and new-database initialization.
- Removed committed runtime logs and expanded ignore rules for nested dependencies and error logs.
- Release verification passed lint, TypeScript checking, 112 tests, a production build, dependency audit, and CodeQL analysis.

## Known limitations

- AI Skill Shield performs best-effort static analysis. A clean report is not a guarantee that a skill is safe.
- It does not execute untrusted skills or provide a runtime sandbox.
- The hosted standard scan works without AI; optional AI review requires provider credentials when self-hosting.
- The CLI does not yet include the web scanner's complete repository audit or 11-axis validation flow.
